- **D-307.** A standing order's `paths` are an allow-list, so they match **anchored at the project root**: a pattern matches a whole path from its first segment, `*` within one segment, `**` across segments, case-sensitively; a path with no `/` matches only a top-level file. AD-113's last-segment and trailing-run rules exist to err toward flagging a sensitive path; on an allow-list they would err toward accepting (`src/**` would accept `vendor/src/x.rs`), against AD-139's own reason for case sensitivity. A package is in scope when both sides of every added, changed, deleted and renamed path match some pattern. The matcher `governor::scope` and its `scope` vector section land in 7.2 with the syntax checks (at most 32 patterns, no `.` or `..` segment, compiled at validation); 7.15 uses it at collection. This departs from AD-139 (P-61). (7.2, 7.15)
