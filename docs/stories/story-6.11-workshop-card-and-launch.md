# Story 6.11: Workshop cards, launch checks, the credential and the launch flow

**Status:** Review

## Story

As the author who launches a workshop run with the same one click as any work order,
I want the card to show the base and its tip, what will not be carried, the hosts, mounts, image, deadline and budget, and the launch to recheck everything on that card's id, prompt hash and plan hash before the engine creates anything,
so that one pointer click on what I saw is the only way a container starts, and the credential reaches only the worker's `create`.

## Acceptance Criteria

1. **Card facts** (AD-107, FR-6, D-239). For a template with `[template.workshop]`, v0.5's `issue_card` (AD-78) adds `WorkshopCardFacts` (ts-rs): base choices (the template's `base` list, each with its tip from `rev-parse --verify refs/heads/<branch>^{commit}` under `GitRule::Workshop`; then the `officina/<name>` branches imported from that template's runs in the last 7 days that still exist, each with its parent run); the default, the first listed base; the count of uncommitted changes (`status --porcelain=v1 -z --untracked-files=normal`); mounts with their state; the allow-list (story 6.6's `allow_list(kind, project hosts)`) with each entry's route (story 6.25, D-611); the image tag, short id and build time; minutes and budget; the credential's kind; readiness, every side-effect-free check of AC 4 shown as its `LaunchRefusal`; `plan_sha256` (story 6.6). The collector supplies the stored facts (catalogue, registry rows, cards); the git, engine and credential-presence calls run on thread `workshop`, and the result returns as an `AuthorRequest` without deadline (review F18). `EditCard::Base(choice)` issues a new card with the same `seq` (D-135, D-215); the base `<select>` offers the closed list only. Proof: core `crates/officina-core/src/orders/card.rs::tests::{a_workshop_card_carries_its_facts, the_first_base_is_the_default, an_imported_branch_names_its_parent, a_base_outside_the_list_is_refused, edit_base_keeps_the_seq}`; host `crates/officina-host/src/workshop/launch.rs::tests::{tips_and_uncommitted_count_come_from_git, imported_bases_older_than_7_days_are_not_offered}` (real git fixture, D-23); CLI `crates/officina/tests/watch.rs::the_collector_never_spawns_docker` extended: the fake engine's and the logging git's logs show no call from the collector thread while a workshop card is issued.
