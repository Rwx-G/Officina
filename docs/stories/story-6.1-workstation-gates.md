14. **The work network check** (D-613, D-611, D-612; owner, on the machine and network the work floor uses, in one session; recorded after the gate 0 entry and before story 6.20 closes). W1, pasted into a Windows PowerShell window in a folder of his choice (it writes `workshop-network-report.txt` there and prints the same lines): the user's proxy settings, WinHTTP's machine proxy, the proxy Windows resolves for each host the workshop needs (PAC and auto-detect included, through .NET's system proxy), the first line a `CONNECT` to `api.anthropic.com:443` through that proxy answers without credentials, and the leaf issuer and chain root seen for `api.anthropic.com`:

    ```powershell
    [Net.ServicePointManager]::SecurityProtocol='Tls12'; $o=@(); $s=Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings'; $o+="ProxyEnable=$($s.ProxyEnable) ProxyServer=$([bool]$s.ProxyServer) AutoConfigURL=$([bool]$s.AutoConfigURL)"; $o+=((netsh winhttp show proxy) -match '\S' | % { 'winhttp: '+$_.Trim() }); $p=[Net.WebRequest]::GetSystemWebProxy(); foreach($h in 'api.anthropic.com','platform.claude.com','claude.ai','downloads.claude.ai','deb.debian.org','github.com','objects.githubusercontent.com','registry-1.docker.io'){ $u=[Uri]"https://$h/"; $q=$p.GetProxy($u); $o+="$h -> $(if($q -eq $u){'DIRECT'}else{$q.Scheme+'://'+$q.Authority})" }; $q=$p.GetProxy([Uri]'https://api.anthropic.com/'); if($q.Host -ne 'api.anthropic.com'){ try { $t=New-Object Net.Sockets.TcpClient($q.Host,$q.Port); $n=$t.GetStream(); $n.ReadTimeout=10000; $b=[Text.Encoding]::ASCII.GetBytes("CONNECT api.anthropic.com:443 HTTP/1.1`r`nHost: api.anthropic.com:443`r`n`r`n"); $n.Write($b,0,$b.Length); $o+="CONNECT without credentials: $((New-Object IO.StreamReader($n)).ReadLine())"; $t.Close() } catch { $o+="CONNECT failed: $($_.Exception.Message)" } }; try { $w=[Net.HttpWebRequest]::Create('https://api.anthropic.com/'); $w.UseDefaultCredentials=$false; $w.Timeout=15000; try { $w.GetResponse().Close() } catch [Net.WebException] { $o+="HTTPS answer: $($_.Exception.Message)" }; $c=New-Object Security.Cryptography.X509Certificates.X509Certificate2 $w.ServicePoint.Certificate; $ch=New-Object Security.Cryptography.X509Certificates.X509Chain; [void]$ch.Build($c); $r=$ch.ChainElements[$ch.ChainElements.Count-1].Certificate; $o+="leaf issuer: $($c.Issuer)"; $o+="chain root: $($r.Subject)" } catch { $o+="TLS check failed: $($_.Exception.Message)" }; $o | Tee-Object -FilePath workshop-network-report.txt
    ```

    ```powershell
    [Net.ServicePointManager]::SecurityProtocol='Tls12'; $w=[Net.HttpWebRequest]::Create('https://api.anthropic.com/'); $w.UseDefaultCredentials=$false; try { $w.GetResponse().Close() } catch {}; $c=New-Object Security.Cryptography.X509Certificates.X509Certificate2 $w.ServicePoint.Certificate; $ch=New-Object Security.Cryptography.X509Certificates.X509Chain; [void]$ch.Build($c); $r=$ch.ChainElements[$ch.ChainElements.Count-1].Certificate; @('-----BEGIN CERTIFICATE-----',[Convert]::ToBase64String($r.RawData,'InsertLineBreaks'),'-----END CERTIFICATE-----') | Set-Content -Encoding ascii officina-ca.pem; "exported: $($r.Subject)"
    ```
