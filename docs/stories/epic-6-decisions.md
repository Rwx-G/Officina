# Epic 6 decisions

What the PRD, the addendum and the code leave open or state twice for v0.6, settled while writing the Epic 6 stories on 2026-10-28 under the owner's delegation of design decisions, then reworked the same day after a review of the stories: every finding accepted as the review words its fix, the existing decisions amended in place with the finding they answer (`review Fn`), and new rules added from D-229 (P-54). Numbering continues the earlier files: principles from P-50, decisions from D-200 (D-170 to D-199 are taken or reserved), so a `P-n` or `D-n` is unique across epics and Epic 6 stories cite all five files. Stories cite these decisions and name the test that proves each one; this file states the rule, never the test data. A later change edits this file with the fact that motivates it, like the architecture.

"The addendum" is `docs/architecture-v0.6.md`. A gate's research notes entry is named by its subject ("the gate 7 entry", "the login entry"); its E-number is the next free one when it is recorded (D-600). Where a rule rests on a behaviour the review states as belief rather than fact, the rule is the safe one and the decision says it is defensive.

## The engine

- **D-204.** `EngineCallKind` is a fieldless `closed_enum!` with `ALL`; `EngineCall` carries its kind and typed inputs, and core builds its vector. `EngineCallKind::is_launch()` is one exhaustive `match`: every kind that creates, starts, copies into, builds or removes is launch; `version`, `info`, `ps`, `inspect`, `image inspect`, `network ls`, `volume ls`, `logs` and `stop` are read. The launch half compiles under `window-authority`, its error type carrying `AUTHORITY_MARKER` (D-9); `execute` built without the feature refuses every launch kind before any process starts, with an error that carries no marker. A host unit test compiled only without the feature iterates `EngineCallKind::ALL` through a resolver pointing at a path that does not exist and asserts the refusal variant, since a spawn attempt would return a different error and `cargo test -p officina-host --lib` builds no fake engine (review F35); a CI step on both jobs runs `cargo test -p officina-host --lib workshop::engine` alone (D-128's pattern, review F5 of Epic 5). `src/` of `officina-host` holds exactly four `expect(clippy::disallowed_methods)` sites (`spawn`, `relay::run`, `git`, `workshop::engine`). (6.3)
- **D-205.** AD-98's call list gains three read calls: `info` (doctor's engine memory and CPUs for AD-123's `max_workers` warning, which no listed call reports, the `EngineKey` settings digest of D-232 and the clock of D-242), and `network ls` and `volume ls` filtered on `officina.managed=1` (AD-104's orphan networks and R48's orphan volumes, which `ps` does not list). Deadlines: AD-98's 30 s applies to `create` and detached `start`; an attached `start` takes its role's: `Packer` 120 s (AD-110), `Inventory` 60 s, a battery phase its plan's limit plus 60 s. `cp` out is D-218's capped stream. This departs from AD-98 (P-51). (6.3, 6.9, 6.10, 6.13)
- **D-206.** (Amended by D-616: the `docker.exe` environment is an allow list; and by D-603: a `login` worker carries no credential name and mounts the login read-only.) Two environments, each one exhaustive `match` in core, golden per case:
  - **The `docker.exe` process** (per `EngineCallKind`, and per role for `create`): the base environment the window passes (D-86) minus `SESSION_ENV_REMOVED`, every `OFFICINA_*` name, `CLAUDE_CODE_OAUTH_TOKEN` and `ANTHROPIC_API_KEY`, names compared ignoring ASCII case on Windows; `NoDefaultCurrentDirectoryInExePath=1`; the `create` of role `Worker` alone adds the one credential name with its value (AD-105), and the `create` of role `Battery` the same name with `battery::DUMMY_CREDENTIAL`, never a value from the base environment; `DOCKER_*` names pass unchanged.
  - **The container** (per `ContainerRole`): `Worker` and `Battery` get AD-102's golden list and the credential's name; `Packer` gets AD-110's git variables and `HOME` on the volume; `Inventory` gets `CLAUDE_PROJECT_DIR`; `Gateway`, `BatteryGateway` and `Decoy` get none. Only `Worker` and `Battery` carry a proxy name or a credential name. The approved image's own `ENV` cannot add a reserved name (D-233, review F13).
  - **What comes back** (review F14): `docker inspect` runs with `--format` selecting `{{json .State}}` and `{{json .Config.Labels}}` only, never the full object, whose `Config.Env` holds the credential's value (addendum section 1 item 10).
